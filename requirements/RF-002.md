# RF-002 — Inicio de sesion

## Descripcion

Autentica a pacientes, profesionales y administradores desde Unity y desde el frontend web mediante el mismo endpoint, manteniendo trazabilidad entre ambos puntos de acceso mediante JWT.

## Criterios de aceptacion

• El usuario ingresa correo y contrasena para autenticarse.
• El mismo endpoint de autenticacion se utiliza tanto desde Unity como desde el frontend web.
• El sistema valida las credenciales y retorna un JWT si son correctas.
• Si las credenciales son incorrectas, el sistema muestra un mensaje de error.
• El JWT permite mantener trazabilidad entre el acceso desde Unity y desde el frontend web.
