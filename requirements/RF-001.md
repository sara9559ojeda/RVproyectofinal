# RF-001 — Registro de nuevo usuario

## Descripcion

Permite que un Usuario Externo cree una cuenta desde la pagina publica, con rol "paciente" forzado, validando que el correo no este previamente registrado.

## Criterios de aceptacion

• El formulario de registro solicita nombre, correo y contrasena.
• El sistema valida que el correo no este previamente registrado.
• La cuenta creada queda con el rol "paciente" de forma automatica.
• Si el correo ya existe, el sistema muestra un mensaje de error y no crea la cuenta.
