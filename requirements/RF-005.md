# RF-005 — Ajuste del grado de exposicion

## Descripcion

Permite configurar el grado de exposicion/fobia antes de iniciar una sesion de terapia, como paso previo al comienzo del nivel seleccionado.

## Criterios de aceptacion

• El sistema permite configurar el grado de exposicion antes de iniciar la sesion.
• La configuracion se aplica como paso previo obligatorio antes de comenzar el nivel seleccionado.
• El grado de exposicion configurado queda registrado junto con la sesion.
