# NeuroPhobia — RVproyectofinal

Proyecto de terapia de exposicion a la aracnofobia mediante realidad virtual (Unity), con analisis de voz por IA y generacion de reportes clinicos.

## Estructura del repositorio

`diagramas/`: diagramas de arquitectura, procesos, base de datos y casos de uso.
`requirements/`: requerimientos funcionales del sistema (RF-001 a RF-012).
`Assets/`, `Packages/`, `ProjectSettings/`, `UserSettings/`: proyecto de Unity.

## Requerimientos funcionales

Cada requerimiento tiene su propio archivo en la carpeta [requirements/](./requirements), y una Issue correspondiente en este repositorio agregada al GitHub Project.

| Ref | Requerimiento |
|---|---|
| RF-001 | Registro de nuevo usuario |
| RF-002 | Inicio de sesion |
| RF-003 | Gestion de perfiles y roles |
| RF-004 | Ejecucion de sesion de terapia VR |
| RF-005 | Ajuste del grado de exposicion |
| RF-006 | Captura y envio de audio |
| RF-007 | Analisis de datos mediante Inteligencia Artificial |
| RF-008 | Generacion y consulta de reporte de sesion |
| RF-009 | Panel del paciente |
| RF-010 | Panel del profesional de salud |
| RF-011 | Panel del administrador |
| RF-012 | Pagina publica de informacion del producto |
